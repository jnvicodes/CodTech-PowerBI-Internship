# Power BI Internship - CodTech IT Solutions

This repository contains the projects completed during my Power BI Internship. It demonstrates data modeling, real-time simulation, and Python integration.

## Project Structure
- **Task 1 & 2:** Sales Dashboard & Data Integration (.pbix)
- **Task 3:** Real-Time Dashboard Simulation (.pbix + .py)
- **Task 4:** Python Advanced Visuals (.pbix + .py)
- **Data:** Raw source file (data.csv)

---

## Task 3: Real-Time Dashboard
**Objective:** Simulate a live API feed updating in real-time.
- **Solution:** I used a Python script as a data source to generate live timestamps (`datetime.now()`) and random values. 
- **Key Feature:** By disabling the default Date Hierarchy, I enabled granular second-by-second tracking.
- **Script:** [View Simulation Script](./task3_simulation.py)

---

## Task 4: Python Integration
**Objective:** Perform advanced visualization using Python libraries.
- **Solution:** Integrated a Python visual using `Matplotlib`/`Seaborn` to create statistical charts not available in standard Power BI visuals.
- **Script:** [View Visualization Script](./visuals.py)
